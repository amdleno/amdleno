## 🚀 Lo que encontrarás aquí
Este repositorio sirve como portafolio y biblioteca de scripts. El objetivo es compartir soluciones prácticas y adaptables (enfocadas en *vendor-neutral* cuando sea posible) para facilitar el día a día de los equipos de Infraestructura y Seguridad.

*   **Automatización de IAM:** Scripts en PowerShell para onboarding, offboarding y auditoría de accesos.
*   **Gestión de Endpoints:** Automatizaciones para Microsoft Intune y SCCM.
*   **SysAdmin e Infraestructura:** Scripts generales (PowerShell/BAT) para administración de sistemas y tareas de red.
